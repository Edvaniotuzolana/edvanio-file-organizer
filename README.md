# Edvanio File Organizer

Ferramenta em Shell Script para organizar ficheiros automaticamente.

## Funcionalidades

- Organizar ficheiros por extensão
- Criar pastas automaticamente
- Mover ficheiros
- Evitar duplicados

## Tecnologias

- Shell Script
- Bash
- Linux

## Execução

chmod +x src/*.sh
./src/organizador.sh
